# Data

This folder contains the datasets used in "Surrogate-Assisted Symbolic Regression
for Electrolyte Solution Property Modelling".

The data were generated/collected within the project funded by the European Union
(Grant Agreement No. 101161366, https://doi.org/10.3030/101161366).

| File | Description |
|------|-------------|
| Cp.csv | Heat capacity data|
| Eta_rho_Aw.csv | Viscosity, density and water activity data |
